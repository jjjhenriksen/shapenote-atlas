## Source-first opening review and correction workload

Source-only top-staff crops were frozen before V7 inference. Blackbird visually read all eight openings, recording the first printed measure/pickup/repeat-start segment (predeclared) and uniformly the next segment (supplemental, observed before reading candidate event lists). The source observations cover **44 events in 16 segments**. This is an agent spot-check, not independent human gold or a whole-page accuracy estimate. The reviewer had first-measure reference events in context before visual reading, so this review was blind to new candidate event lists until observations were saved, **not reference-blind**.

- First segment: **6/8 need correction**; supplemental second segment: **7/8**. Total **13/16**; every tune has at least one affected segment.
- Event-level proposed edit scripts total **34 actions** across this sample. This is a workload proxy, not measured editor clicks, minimum human edits or elapsed correction time. Voice/segmentation repairs can span measures.
- Source readings agree with the candidate reference for these 44 events only; this does not validate the remaining reference corpus.
- Concrete findings: Union loses an eighth rest and misreads B4 as A4; Parting Friends shortens the opening B4 half note to a quarter; Big Creek shortens F5 half to quarter; Calvary stretches its second whole-measure rest to 4.5 beats; Soldier of the Cross adds an A4 beneath a source C5. Edmonds and Eternal Praise also show spurious simultaneous notes/voice reconstruction.
- Pitch/duration/onset only. Lyrics, literal exported head shapes, ties, repeat traversal, all other staves/measures and full musical acceptance were **not certified**.
- **Human correction minutes: unavailable.** No time estimate is inferred from runtime or mismatch counts.

The full automated queue has **1,188 locations with any pitch/duration/measure/onset or insertion/deletion disagreement**. A single early segmentation error can flag many subsequent events. It is a triage queue, not 1,188 confirmed errors or independent corrections.
