# SH1991 fa-template v1: more triangle heads, worse scores

Date: 2026-10-15 America/Los_Angeles (freeze/run timestamps are UTC, 2026-10-16).
Follow-up to the [literal-head audit](sh1991-head-shape-audit-20261015.md) and
[OMR baseline](sh1991-omr-baseline-20261015.md), advancing
[#471](https://github.com/jjjhenriksen/shapenote-atlas/issues/471).

## Decision

**Reject v1. Do not promote it or run its held-out arm.** A narrowly targeted,
opt-in fa-template intervention substantially improves triangle retention in
the saved graph, but harms other head recognition and exported pitch, duration,
and written measure/onset agreement. Six of nine predeclared gates fail.
The original source scans, baseline engine, and previous outputs are preserved.
No model was fine-tuned, no source pixels changed, and no paid/hosted inference
or source upload was used.

The strongest positive result is real but narrow: filled triangles go from
9/44 retained with **zero** correct fill to 42/44 retained with **all 42**
correct fill. That does not rescue the full pipeline.

## Controlled intervention

Audiveris's stock pitched-staff head vocabulary excludes its existing
percussion triangle templates. Those templates are not Sacred Harp's right-angle
fa heads. On a separate copy of upstream commit
`9e1e55cd2746037d059345881c53e6a6754bffbd`, the prototype adds:

- Four logical, non-percussion fa heads: open/filled in two printed orientations,
  using Bravura SMuFL glyphs `E0BF`, `E0C0`, `E0C8`, `E0C9`.
- Template hole masks and stem anchors, intrinsic fill-dependent durations,
  and pitched MusicXML `fa` / `fa up` with explicit fill state.
- A default-off `faHeads` processing switch. No physical-classifier vocabulary
  was retrained or extended.

Both arms use the **same patched binary**, original full-frame scans, five
previously selected training images (**26, 83t, 68b, 72b, 89**), and identical
constants except `faHeads=false` versus `true`. The protocol was frozen before
the runs, and the engine/patch identities were frozen before recognition.
Batch CLI constant persistence is disabled; template-note diagnostics are
enabled in both arms. All five off-control exports have identical written
pitch/duration/measure/onset events and per-part measure counts to the original
engine exports. This is event equivalence, not byte-identical MXL archives or
proof every inactive code path is identical.

The four focused Java tests passed: logical/pitched vocabulary membership,
fill-dependent intrinsic durations, real open-template interior holes, and
absence of hole masks in filled templates. These structural tests do **not**
prove scan recognition quality or correctness of the exported score.

coordinate adjudications applied identically to both arms. Matching is
one-to-one, distance-only, within 0.5 staff interline. Shape and fill do not
enter the matching cost. These are single-AI observations, not independent
human ground truth.

## Failure analysis and next experiment

1. **Open/filled discrimination remains broken.** Fifteen of the sixteen
   recovered open triangles have the wrong fill. Filled-template success and
   unit-tested hole masks do not establish that competing templates are
   ranked correctly on scanned notation. Investigate masks, scoring, and
   filled/open competition with source-only training crops; do not infer fill
   from pitch, key, or the existing XML.
2. **Template competition damages other shapes.** Five previously retained
   non-triangle locations disappear, and 40 retained non-triangle locations
   receive fa labels. Unmatched graph candidates also increase sharply. A v2
   must evaluate localization *and* shape precision on all four head families,
   rather than optimizing triangle recall alone.
3. **Graph retention is not score recovery.** Audited triangle retention rises
   while the five-image export loses more than half its pitched events.
   Samaria's on-arm log reports `StackRhythm` and `PartBarline` errors despite
   exit code zero and a parseable export. Inspect head–stem/chord associations,
   graph pruning, barline topology, rhythm reconstruction, and export losses.
   These observations do not isolate the precise causal path or prove that
   stem anchors alone are the defect.

Next recommendation: keep v1 frozen as a negative result. Create a separately
versioned training-only v2 with per-head competing-template scores,
orientation/fill confusion, source-reviewed negative locations, and
head→chord→rhythm→export survival accounting. Preserve the existing score and
alignment gates. Do not tune on held-out images to make this intervention pass.
No v2 inference or engine modification is part of this result.

- Restricted inputs, engine binaries, graph archives, logs, and run receipts
  stay in ignored `work/model-pilot/sh1991-v1/`; they are not redistributed.

On resumption after the transport failure, the build, four Java tests, ten
recognition runs, decision, and JSON report were already present. They were
not repeated. The remaining work was this failure report, replay metadata
preparation, cache/selection regression tests, and a local checkpoint. Analysis
was replayed from the saved artifacts, not mistaken for new recognition.

Resumption verification: **21 clone-safe Python tests passed**; the saved
four-test Java receipt and live retained engine fingerprint matched their
frozen hashes; the patch passed `git apply --check` on the pinned baseline
source; all recorded metrics/decisions reproduced; and all **301 inventoried
source/run files remained byte-identical**. The earlier JSON report is retained
locally as `fa-template-v1/report-before-resume.json`; the checked-in result
updates only the analysis-script hash, not the measurements or frozen engine.

No fa-template held-out recognition ran. The eight test images had been used
by earlier baseline/voice-isolation experiments; they are not globally unseen
data. This result neither closes #471's independent source-review and
model-adaptation criteria nor establishes usable-page rates, human correction
time, lyric alignment, ties/slurs/repeats fidelity, or cross-book generalization.
