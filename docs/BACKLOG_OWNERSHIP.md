## Handoff is quarantine, not admission

The existing `scripts/import_transcription_bundle.py` verifier requires an
out-of-band expected manifest hash and stages only into ignored
`work/transcription-imports/<hash>/`. It changes no public corpus/assets,
publication, playback or score acceptance. There is no new promotion flag.

The [separate acceptance-contract task](https://github.com/jjjhenriksen/shapenote-atlas/issues/495)
must be satisfied before publication/admission work. Every handoff needs full
producer revision, exporter hash, manifest/payload hashes, **actual** assembly
implementation hash, source identity, private retained-evidence locator, actual
extent, unsupported semantics and source-review disposition. Integrity, parsing
and engraving do not establish musical fidelity, rights or approval. Preserve
predecessors and restrictions; verify actual editable bytes, honest UI labels,
written/repeat playback and separately scoped release QA.

The [capability prerequisite](https://github.com/jjjhenriksen/shapenote-transcriber/issues/8)
keeps unsupported seven-shape/textural/semantic material blocked rather than
coercing it into the current four-monophonic-part/four-shape adapter. No model
training, source fetch/transcription, redistribution, automatic promotion,
deployment or native-window QA is performed by migration.
